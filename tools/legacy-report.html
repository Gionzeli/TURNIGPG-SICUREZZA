Rapporto locale dei backup legacy

Strumento di sola lettura per analizzare un export JSON o confrontare più export. L'analisi avviene nel browser sul dispositivo in uso.

Privacy: i file sono letti solo in memoria da questa pagina. Non vengono caricati, trasmessi, salvati in LocalStorage o IndexedDB, né inviati a servizi esterni. La pagina non effettua richieste di rete; importa solo il modulo locale dell'adapter DSM.

Usa solo copie degli export non cifrati. Non selezionare file con password, PIN, hash o salt. Conserva intatti gli originali.

Da 1 a 100 file, 10 MB ciascuno e 50 MB complessivi. Con un file viene eseguita l'anteprima singola; con più file anche la riconciliazione. Il rapporto usa etichette generiche (Export 1, Export 2…) e non include i nomi dei file.
